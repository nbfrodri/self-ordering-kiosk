# Screenshot notes and photo credits

These are browser captures of the running application, using an isolated local Docker instance. Product images were uploaded through the application's existing admin API and stored in its databases. The images are illustrative stock photography for a sample menu.

The capture setup starts from the seeded catalog, adds photographs to the five burger products, marks Classic Burger as featured and orders the products for the menu. The Bacon BBQ Burger sample is renamed Truffle Cheeseburger to match its photo, with the description "Beef, melted cheese, truffle and crisp seasonal greens." These presentation changes belong to the temporary demo data; the default database seeder is unchanged.

The customer view contains Classic Burger and Chicken Burger in the cart. Checkout uses simulated credit-card payment and a fictional customer named Demo. Kitchen and analytics captures also contain sample orders, not production activity.
